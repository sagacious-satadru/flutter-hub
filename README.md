# Flutter Learning Pathway

Projects built while working through the official [Flutter learning pathway](https://docs.flutter.dev/learn/pathway).

Each subfolder is an independent Flutter app — `cd` into one and run the usual `flutter pub get` / `flutter run` from there.

## Projects

| Folder | Pathway section | Description |
| --- | --- | --- |
| [`birdle/`](birdle) | Introduction to Flutter UI | A Wordle clone (Bulls and Cows-style word guessing game). |
| [`wikipedia_reader/`](wikipedia_reader) | State in Flutter apps | An app for browsing Wikipedia article summaries, built while learning state management and HTTP requests. |
